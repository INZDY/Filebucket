# Bulk Selection Uses a Selection-Mode Toggle, Not Click-Select / Double-Click-Open

Filebucket's Folder Contents View needs bulk operations (Move, Move to Trash, Download ZIP) across multiple items. We chose a dedicated selection-mode toggle ("Select"/"Cancel" in the Folder Contents View breadcrumb bar) that temporarily changes card click behavior, rather than adopting a permanent Google-Drive-style interaction where a single click selects and a double-click opens.

The permanent click-select model was rejected because it rewrites the Folder Contents View's existing interaction contract (where selecting a folder navigates into it), is unreliable on mobile (double-tap detection conflicts with the existing long-press sheet), and would impose the new model on every mode. The alternative of an event-capturing overlay layer over each card was also rejected: it is unnecessary, since cards are link elements whose navigation can simply be suppressed by a mode flag, and it risks breaking interactions in folders containing many files. The chosen design keeps single-click-open as the default, isolates bulk behavior behind the toggle, and implements selection as client-side state local to the workspace component.
